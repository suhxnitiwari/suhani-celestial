# Celestial

My birth chart, a little less sciency. Pisces Sun, Gemini Moon, Taurus Rising.

This started as the **Celestial** tab in the Personality section of [suhanitiwari.com](https://suhanitiwari.com), and now it has its own home.

**Live site:** https://suhxnitiwari.github.io/suhani-celestial/

## What's here

- `index.html`: the whole page on its own (styles and script inline, no build step). Click a placement in the list or a planet on the wheel to read it.
- `original/Celestial.cshtml`: the original Razor source from the portfolio (`Views/Home/Index.cshtml`), kept word for word. It holds the chart data and the math that places each planet on the wheel.

Not real science. Fun science. Think girl math, but make it cosmic.
